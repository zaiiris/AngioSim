# Arduino

Current sketch:

```text
heart_pulse_flprog_generated.ino
```

This sketch was generated by FLProg from `hardware/flprog/heart_pulse.flp`.

## Dependencies

The generated sketch includes:

```cpp
#include "flprogUtilites.h"
#include <Wire.h>
#include <LiquidCrystal_I2C.h>
#include <EEPROM.h>
```

To compile it in Arduino IDE, the project also needs the FLProg generated/support file `flprogUtilites.h` and the `LiquidCrystal_I2C` library.

## Current pin map

```text
D2  - pulse input from the circulation/flow sensor
D4  - menu/down button, INPUT_PULLUP
D5  - value up button, INPUT_PULLUP
D6  - value down / stop button, INPUT_PULLUP
D7  - start/reset cycle button, INPUT_PULLUP
D9  - output, inverse of D13
D13 - output, main circulation control signal
I2C - 16x2 LCD, address 0x27
```

## Current behavior

- counts sensor pulses from `D2`;
- converts pulses to liters using `pulses / 2800.0`;
- stores target volume in EEPROM as liters + milliliters;
- supports a continuous mode named `Neprerivno`;
- starts circulation with `D7`;
- stops when target volume is reached, unless continuous mode is enabled;
- also stops with `D6`;
- shows current volume, target volume, menu values, and cycle count on LCD.

The current sketch does not yet send Serial JSON to the backend. That is the next integration step.
